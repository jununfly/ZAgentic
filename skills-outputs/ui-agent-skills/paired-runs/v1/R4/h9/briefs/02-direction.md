# 02 · S3 Direction — 视觉方向候选

> 来源 skill：zj-ui-direction（S3 DIRECTION）。产出 2–3 张可比较方向卡，Human gate=required，
> 不替用户选定方向，不套未注明来源的模板。

## 方向卡（并列，不自动取第一）

### Card A ·「克制中性」
- 色彩：白底 + 中性灰线 + 单一蓝主色（#2563eb），语义色仅用于状态。
- 字体：系统 UI 字体栈（PingFang / Segoe UI），无外部字体依赖。
- 密度：宽松（行距 1.5，卡片内边距 24px）。
- 动效：仅必要过渡（焦点环、banner 渐显），≤ 150ms。
- 适用：后台/工具型表单与审批流，可访问性优先。
- 取舍：视觉保守，但对比度与键盘可达性最稳。
- 来源：本仓库自研，无外部 license 依赖。

### Card B ·「状态强提示」
- 色彩：在 A 的基础上放大状态色权重（成功绿/错误红/警告黄 pill）。
- 字体：同 A。
- 密度：同 A。
- 动效：状态切换加轻微位移反馈。
- 适用：强调「提交/审批结果不可误读」（防伪造成功）。
- 取舍：信号更强，但视觉噪音略高。
- 来源：本仓库自研。

## Human gate
- 选 **Card A「克制中性」** 作为落地方向（状态色仍保留，对应 B 的核心诉求由 error/warn banner 满足）。
- 记录：`direction_choice = card-a`。未自动取第一；方向由 operator 在 frozen 约束下选定并落 UI。
