共同约定

  • 提交与审批都是手动动作：确认勾选 + 点击按钮，两步都在同一次交互里，系统不会替你点。
  • 提交中输入锁定，重复点击不会产生第二次写入。
  • 服务端 422 与服务端超时都可复现：422 可以改完再提交；超时只显示「结果未知」，并留在当前页。
  • 审批只接受审批人角色，越权调用会被拒绝，单据停在原状态。

页面通过 ES Modules 加载 src/**/*.mjs，请用本地静态服务器打开（例如 python3 -m http.server），直接双击 file:// 打开会被浏览器的模块策略拦截。
