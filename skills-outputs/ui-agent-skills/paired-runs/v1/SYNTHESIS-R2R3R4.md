## 4. 可以说的结论（有限定词，一个都不能少）

> 在 **AI-operator、契约层、n=3 paired run（R2+R3+R4）** 条件下，`skills-path` 相比 `direct-prompt`：
> **逃逸缺陷的严重程度平均约低 40–55%，但代价是返工约多 3 倍、工具调用约多 48%、墙钟在 R2/R3 约多 3.5 倍（R4 持平）。且该质量优势在 R4 退化为零（两 lane 打平）。**

限定词：
- **AI-operator**：DEV-2——"决策时间"是 operator 完成时延，不是人类决策时间；结论 scope 收窄为"AI-operator 下的 artifact 质量与操作效率"，**不得声称改善人类 UX**。
- **契约层**：渲染层/键盘可达性未实测（BLK-3，无浏览器）；本 cohort 的 escaped defect 全为静态推导（两 lane 证据均为 static，R-BAL 达标）。
- **n=3**：满足 ev-metrics §1 的最低次数，但**每个 lane 仅 3 个样本**，且 R4 单点打平说明方向不稳健。
- **direct-prompt 的对照组 = 同一模型不接技能链**，不是"人类工程师"。

## 5. Graduation gate 判定（控制器分析，zj 终审）

按 `ev-metrics` 阈值（返工≥20% / 时延≥15% / escaped≥20% 作 AI-operator 口径判据）：

- **质量信号弱且非鲁棒**：加权缺陷 skills 均值更低（8.0 vs 13.33），但仅 2/3 run 同向、R4 打平；high 同理。阈值"escaped≥20% 改善"**未被稳定证明**。
- **成本信号清晰且一致为负**：返工 +303%、调用 +48%、墙钟 +357%（R2/R3）——skills-path 在三次 run 中**始终更贵**。
- **渲染层缺失（BLK-3）**：技能链最可能改善的恰是 a11y/视觉层，而该层从未实测，所以"skills 是否有独特价值"在最有价值的地方**无证据**。

**控制器建议结论：`skills-path` 未通过 graduation gate 作为"质量胜出"判定。** 在契约层 + AI-operator 口径下，技能链 ≈ **平价但更贵**；不构成稳健的毕业/采纳依据。最终 gate 由 zj 批准（run owner 不自裁，ev-metrics sub-06 P4）。

## 6. 比毕业结论更值钱：契约层三类系统性盲点

三轮（R1→R4）fixture 全绿（12/12 × 6 lane）**从未阻止**以下缺陷，且两 lane 都出现：

1. **状态迁移在 UI 上不可达**（R1 h4）——fixture 用 `initial_state` 直接注入，跳过 transition。
2. **静默数据丢失 / 伪成功**（R3 h7/h8 两 lane 都栽；R4 因 driver 更紧而未见，但同类代码模式仍在）——需求明写"超时不能让用户以为保存成功"，无对应门禁。
3. **非法迁移返回值被吞**（R2 h5 critical：idle→submitting 非法却照常 `locked=true`）——状态机返回值没人检查。

共同点：**都是"契约层测不到、用户层才暴露"**。→ 给 `zj-ui-verify` 补三类机械门禁：**迁移可达性**（已有 v4）、**失败不得渲染为成功**、**状态机返回值必须被检查**。这比毕业结论本身更有长期价值。

见 §6。三条系统性盲点应转化为 `zj-ui-verify` 的强制机械门禁，覆盖全部 lane。
