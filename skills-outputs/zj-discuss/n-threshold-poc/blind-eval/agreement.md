## 2. 一致率

- **二值有效性一致率 = 13 / 15 = 86.7%**
- 三级（真有效 / borderline / 注水·回声）一致率 = 13 / 15 = 86.7%（2 处差异均在
  「borderline 注水」这一级，未跌入「注水」级，故三级与二值同值）。

## 3. 分歧分析（2 处）

| 位置 | 盲标 | 原标 | 性质 |
|---|---|---|---|
| B 条目 3（原 v5 停止规则） | 真有效 | borderline 注水 | 原标**更保守**：把低增量真实缺口判为非真有效 |
| C 条目 1（原 v3 差异化价值） | 真有效 | borderline 注水 | 原标**更保守**：同上 |

> 两处分歧方向一致：原始标注在 borderline 边界**更严格**（少算真有效），盲标更宽松。
> 即 PoC 的「真有效饱和条数」（B=4 / C=2 / A=4）若按盲标口径只会**更多或更持平**，
> 不会更少。原 N 校准（B/A=3、C=2）基于保守计数，结论**稳健不脆弱**。

## 4. 结论（按协议 §5 判据）

- 一致率 **86.7% ≥ 80%** → **支持原校准**：N 判定可进入节点 1-4 跨会话复核
  （满足节点 1-1 决策 A 的「证据可复现」门槛）。
- 分歧仅落在 borderline 层且方向为原标更保守，不构成对 N=3 / N=2 结论的挑战；
  反而印证原计数保守、结论稳健。
- **未触发**节点 1-1 决策 D（拒绝/升级）与 1-5 阻塞条件。

## 5. 诚实局限（写回 roadmap 决策）

- 本执行是**同 Agent 操作性盲评**：通过剥标注 + 打乱 + 隐藏原标签实现操作盲，
  但标注者仍是生成 PoC 的同一智能体函数 → 检验**规则自洽性**，不替代
  **跨标注者信度（inter-rater reliability）**。
- 真独立复核（跨会话 / 跨人）属于**节点 1-4（真·跨会话 PoC）**，应报告 Cohen's κ。
- 建议 1-4 在跨会话变体中额外验证 borderline 两处的稳定性（C solo 第 3 条尤其关键）。
