# R1 闸门阈值 N 校准 —— 盲评协议（节点 1-3）

> 本文件是 `r1-closure.roadmap.json` 节点 1-3 的 artifact：定义「剥标注盲标 + 一致率」
> 的方法论，使 PoC 阈值判定的**可复现性 / 客观性**可被独立复核，缓解节点 1-1 决策 A
> 所标记的「同会话自指偏差」风险。

## 0. 目的与边界

- **目的**：验证 PoC 对每条 viewpoint 的「真有效 / 注水 / 回声」判定**是否遵循一致可复现的规则**，
  而非作者临时拍脑袋。一致率高 ⇒ 原 N 校准的判定基础可靠 ⇒ 可进入节点 1-4 的跨会话复核。
- **边界（诚实声明）**：本节点执行是**同 Agent 操作性盲评**（operational blind re-rating）——
  通过「剥标注 + 打乱条目顺序 + 隐藏原始标签」使标注者无法锚定原判定，但仍由同一智能体函数执行。
  这检验的是**规则自洽性（rubric self-consistency）**，不是跨标注者信度（inter-rater reliability）。
  **真正的跨会话 / 跨标注者独立复核属于节点 1-4（真·跨会话 PoC）**，本节点为其建立可复用协议。

## 1. 输入

- 原始探针产出：`probe-views.md`（含 base {B, C, A} 各 5 条 viewpoint，附 `[真有效]` /
  `[borderline 注水]` / `[注水:子类]` / `[回声X]` 标注与 inline `标注：` 注记、各角色小结、汇总表）。
- 被测原文：`docs/agreements/open-source-capability-fit-decision-model.md`（133 行，SSOT，独立素材）。

## 2. 剥标注规则（生成 blind 版）

脚本 `strip_blind.py` 对 `probe-views.md` 做确定性变换，产出 `probe-views.blind.md`：

1. 删除所有加粗有效性标签：`**观点 N [标签]**` → `**观点 N**`（标签整体剥离，编号保留）。
2. 删除所有 inline `标注：` 行（原作者的主观注记）。
3. 删除各角色 `**X 小结**：…` 行（含「真有效饱和条数」等结论性标注）。
4. 删除 `## 汇总数据表` 及其后的汇总 / 拐点识别段。
5. 删除顶部「自指偏差声明」行（避免 priming 标注者）。
6. **打乱**：每个角色内 viewpoint 条目随机重排并重新编号为 `条目 1..N`，
   使标注者无法凭「第 5 条」锚定原 borderline/注水位置。
7. 保留角色分段（echo 检测需跨角色比对）与「发现 / 影响 / 建议」正文。

## 3. 分类方案（盲标标注者使用，与原 PoC 同 rubric）

- **真有效**：有特指原文行号的具体发现 + 独立影响 + 非回声 / 非复述的可执行建议。
- **borderline 注水**：弱、信息增量低、与同角色另一 viewpoint 相邻且逼近注水。
- **注水**：复述 / 空泛 / 无证据 / 硬凑（无独立信息）。
- **回声X**：与另一角色的某 viewpoint 实质重复（角色独立性失效）。

盲标时标注者**只读 `probe-views.blind.md`**，不得回看原文件标签。

## 4. 一致率度量

- **主指标（二值有效性一致率）**：将每条 viewpoint 映射为 {真有效} vs {非真有效}（borderline/注水/回声
  均归非真有效），逐条比对盲标与原标，一致率 = 一致条数 / 总条数（15 条）。
- **次指标（三级一致率）**：{真有效} / {borderline} / {注水·回声} 三级比对。
- **可选**：Cohen's κ（校正随机一致），留待节点 1-4 跨标注者时使用。

## 5. 接受 / 拒绝判据（与节点 1-1 A–E 对齐）

| 一致率 | 结论 | 处置 |
|---|---|---|
| ≥ 80% | 支持原校准 | N 判定可进入节点 1-4 跨会话复核（满足 1-1 A 证据可复现） |
| 60%–80% | 警告 | 节点 1-4 须引入独立跨会话标注者并报告 κ |
| < 60% | 原标注不可靠 | 触发 **节点 1-1 D 拒绝/升级**：回 1-4 重做标注，阻塞 1-5 |

## 6. 输出物

- `blind-eval/probe-views.blind.md` —— 剥标注 + 打乱后的盲版。
- `blind-eval/blind-labels.md` —— 盲标标注者的逐条判定（含理由）。
- `blind-eval/agreement.md` —— 原标 vs 盲标对照表 + 一致率 + 判据结论。

## 7. 已知局限（写回 roadmap 决策）

- 同 Agent 操作性盲评，检验规则自洽，**不替代** 1-4 的跨会话 / 跨标注者独立复核。
- 打乱仅在角色内、保角色分段，故 echo 检测仍可跨角色进行；若需完全盲化角色身份，
  应在 1-4 另设「角色匿名 + 跨会话」变体。
