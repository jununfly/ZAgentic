# R1 闸门阈值 N 校准 PoC 协议

> 对应 `docs/designs/zj-discuss/design.md` §10.6 R1（闸门过严致角色产出萎缩）。
> 目标：用真实角色产出数据，确定 base {B,C,A} 的合理闸门阈值 N（当前 base 初值 N=3）。

## 被测对象（真实原文，非本次产物）

- 文件：`docs/agreements/open-source-capability-fit-decision-model.md`（133 行，本仓库 SSOT）。
- 选取理由：真实、非平凡、结构化；base 三角色均可独立发声；**且为内部方法论文档（solo 场景）**，
  能直接暴露 C（产品专家）在「无真实市场信号」时的视角萎缩风险，正是 R1 风险源。
- 非循环：该文件是既有 SSOT，不是本次 N 校准的输出。

## 被测角色

- base 必需集 **{B, C, A}**：
  - B 技术经理（落地 / 代价 / 谁来做 / 验收）
  - C 产品专家（用户价值 / 生态·竞品参照；solo 场景市场原义空转）
  - A 架构师（约束 / 长期一致 / 边界不变式）

## 独立变量

- 闸门阈值 **N ∈ {2, 3, 4, 5}**：即要求该角色视角产出 **≥N 条带证据有效观点**（三字段：发现+影响+建议）。

## 控制 / 常量

- 每个角色严格按各自 `references/role-methods/<key>.md` 的 gated method 牙齿产出：
  ① Read 原文 ② 角色专属核查清单 ③ 强制三字段输出 ④ 闸门（结构错位 + 原文证据 + 非首轮锚定）。
- 产出由本 Agent 在**同一会话**模拟三个独立视角（受限于环境，非真跨会话隔离）。

## 度量（因变量）

对每个 (角色, N) 组合记录：

1. **真实有效观点数 E**：通过牙齿的观点数（结构错位 + 引用原文证据 + 非回声）。
2. **边际注水位置**：第 k 条观点 (k > 饱和点) 的性质分类——
   - 真有效：独立推理、有原文证据、与已列观点不重复；
   - 注水：复述原文无新增 / 空泛赞同 / 回声其它角色 / 无原文证据 / 硬凑第 N 条。
3. **角色独立性**：该角色视角与另两角色视角的重复 / 回声率。

## 判定线（calibration target）

取使「真实有效观点数 == 要求 N 且边际注水率 ≈ 0」的**最大 N**。
超过该 N 后边际观点注水率陡升 = 闸门过严 → 角色产出萎缩拐点（R1 风险兑现）。

## 诚实声明（自指偏差）

被测样本由**本 Agent 同会话产出**，作者即评审，存在自指偏差。
本 PoC 结论为 **base 初值建议**，须在真实跨会话独立 Agent 讨论中由 Human 复核确认
（与 `design.md` 既有口径一致：跨会话隔离生产仍靠 Human 另开会话）。
