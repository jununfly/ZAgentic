## A 仓关键约定（接手必读）

### 1. 双平台 sidecar 强制
- **Claude 平台**: SKILL.md frontmatter 加 `disable-model-invocation: true`（user-only skill）
- **Codex 平台**: `agents/openai.yaml` 含 `policy.allow_implicit_invocation: false`
- interface only skill（model 可调）用 openai.yaml 但**不**加 policy 段

### 2. zj-git 包装协议（shim 防护）
- WorkBuddy 注入 `genie-safe-delete.cjs` shim 会在 Windows Git Bash 上把 `rm -rf` 真删
- **所有** git 操作用 `env -u NODE_OPTIONS git` 或 `./scripts/zj-git` 包装
- Skill 详见 `skills/engineering/zj-git-bypass-safe-delete/`
- 替代方案: `mv <target> <backup>/` 优于 `rm`

### 3. Roadmap 操作协议
- **唯一 CLI**: `python3 "C:/Users/jununfly/.workbuddy/skills/zj-roadmap-driven/roadmap_cli.py" <cmd>`
- 写类命令需串行（CLI 有 per-roadmap lock）
- **禁止直接 Edit/Read json 文件**——通过 CLI 改
- md section 由 `render` 命令完全重写，手动改会被覆盖
- status 自动同步：**只在 children 结构变更时触发**（add/update --status），单纯 decide 不触发
- **路径注意**: 用 `C:/Users/jununfly/...` 格式（Windows 原生路径），不要用 `/c/Users/...`（MSYS 会错误转换）；用户名是 `jununfly` 不是 `junanfly`（常见拼写错误）

### 4. PR 标志 3 rule (1-3-3-1 A-only)
- **Rule 1**: skills/ 改动必查 `.codex-plugin/plugin.json` 挂接
- **Rule 2**: git 操作必走 `./scripts/zj-git` 包装
- **Rule 3**: 新术语必先更新 `ZJ-CONTEXT.md` 才合并

### 5. 词汇表
- `ZJ-CONTEXT.md` (仓根目录) — 领域词汇表
- `AGENTS.md` — 仓库约定硬规则（plugin.json 挂接 / bucket 划分）
- `~/.workbuddy/MEMORY.md` (用户级) — shim 根因 + 4 条硬规则 + 检测特征

### 6. 烤问漏点教训
**别让 Agent 编理由, 必须让用户烤问**。如发现 notes 里出现"X 是中性名"等自圆其说的表述, 大概率是 Agent 编的, 立即烤问用户。
