### Concepts

调 `zj-domain-modeling` 提取本次工作新出现的概念，已写入 `ZJ-CONTEXT.md`
（Codebase documentation 段，Architecture handbook 之后）：

- **Architecture map** — 架构手册的路由页，链接每个视图一次并标注 `authority-id`；只路由不重述。
- **Architecture view** — 五种互补页面类型之一（overview / layers / subsystem / flow / cross-cutting），文件名用 `ta-` / `ba-` / `pa-` 前缀。
- **View contract** — 每种视图在通用 5 段之外必须提供的专属 heading 集合（例：flow 视图必须给 trigger / sequence / state and effects / failure or exit behavior / observable evidence）。
- **Source map target** — `## Source map` 段内命名的路径；validator 从仓库根解析，因此必须写 root-relative 路径而非相对所属 skill 的路径。
- **Bucket discipline** — 横切规则：bucket 是公共入口、`personal/` 是平行路径而非第六个 bucket、架构页不复制 design/ADR 权威。
- **5 + 1 model** — 五个公共 skill bucket 加一个根级 `personal/` 树。

（原有术语 `Architecture handbook` / `Authority ID` / `Document contract` /
`Personal skill tree` 已存在，仅做链接引用，未重复定义。）
