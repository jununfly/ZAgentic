# Research

Research methods and evidence-to-report seams. Domain-specific cleaning and
analysis belong in the owning research method; this bucket does not promise one
universal research workflow.

- **[zj-research](./zj-research/SKILL.md)** — Produce cited primary-source findings or a sealed evidence ledger with provenance and explicit unknowns.
- **[zj-code-research](./zj-code-research/SKILL.md)** — Build a commit-scoped Repository Map, then deep-read selected code architecture with evidence-linked claims.
- **[zj-tech-research-report](./zj-tech-research-report/SKILL.md)** — Turn technical findings and sealed ledgers into compiler-validated technical-solution research reports.
- **[zj-systematic-research](./zj-systematic-research/SKILL.md)** — 用横纵分析法研究产品、公司、概念、技术或人物，重建演进脉络并分析当下格局。
